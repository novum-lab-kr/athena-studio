# Security Policy

## Reporting a vulnerability

Please **do not** report security problems in public issues, pull requests or discussions.

Report them privately through GitHub instead:

- Go to the **Security** tab of this repository and choose **Report a vulnerability**, or
- open https://github.com/novum-lab-kr/athena-studio/security/advisories/new

Include what you found, the steps to reproduce it, and the Athena Studio version (menu bar → **Athena → About Athena**) and macOS version you used. Do not include real secrets, tokens or company code in the report.

## Supported versions

Only the latest release of Athena Studio is supported. Please check that the problem still happens on the latest release before reporting.
