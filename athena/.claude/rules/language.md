# 언어 규칙

- 한국어로 소통, 코드 주석도 한국어
- 영어는 코드, 파일명, 기술 용어만 허용
- 단, Athena Studio 에서 고른 언어가 있으면(훅이 메시지마다 `[언어 설정]` 으로 알려 준다 — `scripts/hooks/language.py`) 그 언어가 위 두 줄보다 먼저다 — 답 · 계획서 · 이슈 · 커밋 메시지 · 코드 주석 모두. 템플릿의 제목 · 항목 이름은 스크립트가 읽으니 그대로 둔다
- 확인하지 못한 내용은 사실처럼 쓰지 않고 "확인 못 함"이라고 명시 — 추측으로 구현하지는 않는다(`AGENTS.md` 5절)
