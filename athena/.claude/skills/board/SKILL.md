# 일감

인자: $ARGUMENTS

## 동작
`scripts/board.sh [stop|url|open <계획서>]` 을 실행한다. 이 스킬 자체는 코드나 문서를 수정하지 않는다(쓰기는 사용자가 화면에서 한다).

- 인자 없음: 서버가 없으면 백그라운드로 띄우고(pane 없이 · 로그 `/tmp/hermes-board*.log`) 브라우저를 연다(Athena Studio 면 그 창의 옆 브라우저). 이미 떠 있으면 브라우저만 연다
- `stop`: 서버를 끈다 · `url`: 주소만 출력
- 표준출력의 주소와 띄운 곳을 한 줄로 전한다. `⚠️` 가 나오면 그대로 전한다

## 보여주는 것 (3초마다 모아 바뀌면 화면에 밀어 준다)
| 영역 | 어디서 읽나 |
|---|---|
| [이슈] 탭(첫 화면) — 해결할 이슈 | `issues/*.md` 중 끝나지 않은 것(`status` 가 done · wontfix 가 아닌 것) — 학습 후보(`kind: knowledge` · `*-learn-*.md`)는 뺀다. 한 줄에 제목 · 레포 · 중요도 · 등록일 · 등록 경로 · 요약. 열린 이슈는 [작업 시작] · [삭제], 시작한 이슈는 "진행 중" 과 맡은 에이전트 pane(이슈 `plan:` 계획서의 Work ref pane — 막힘 · 완료 가능 배지). 진행 중 먼저, 그다음 중요도 · 최근 등록 순 |
| [QA] 탭 — QA 시뮬레이션 런 | `.qa-runs/` 런 목록(최신순) → 런 하나의 영향 화면 카드(판정 · 작업/기준/차이 스크린샷 · 문제 원문 · 리포트 링크). 돌고 있으면 1.5초마다 갱신. 계획서 카드의 [QA 실행] 은 칸반과 함께 빠졌다(2026-10-26) — 영향 화면 QA 는 아테나에게 말로 맡기고, 이 탭의 [전체 검수 시작] 은 그대로다 |
| [학습] 탭 | 아테나 학습 — 학습 후보 `issues/*-learn-*.md`(이슈 목록에서 빠진다)·학습한 내용 `docs/knowledge/learned/`(`scripts/board/learn.mjs`) / 클로드 학습 — Claude Code 메모리(`~/.claude/projects/<워크스페이스>/memory`, 읽기 전용) |
| [아카이브] 탭 | `archive/` 보관한 일 |

탭 순서: 이슈 · QA · 학습 · 아카이브 · 지표(뒤 넷은 작게). 계획서 칸반 · [정비] 탭 · 지금 동작 중 · 워크트리 칸은 없다(2026-10-26 결정 D6) — 계획서 진행은 Athena Studio 의 [작업] 팝업과 pane [상세] 에서 본다. 서버는 계획서를 그대로 모아 `/api/state` 로 내보낸다(앱 [작업] · [상세] · 메뉴 막대가 쓴다).

에이전트 pane 이름(`🤖 <에이전트> · <브랜치>`)의 브랜치나 pane id 가 계획서 `Work ref` 에 있으면 그 계획서에 붙는다. 계획서를 맡긴 아테나 pane 은 `- Lead pane:`(delegate.sh) · 결정 콘솔 `leadPane` 이다.

## 화면에서 할 수 있는 것
| 동작 | 무엇이 바뀌나 |
|---|---|
| 끝난 일 **자동 보관** | 계획서 PR 이 모두 머지돼 완료(PR 없는 계획서는 완료) + 배우기 검토 끝(`- Learn review:` 줄 · 대상 아니면 건너뜀) + 그 계획서에 묶인 에이전트 pane 이 모두 닫히면 그 자리에서 **`archive/<이름>/` 한 폴더**로 묶는다 — `issue.md` · `plan.md`(· 정식이면 `plan.html`) · `meta.json`(보관 시각·원래 경로), 서로 가리키는 경로도 새 위치로. 이슈는 연결 계획서와 함께(계획서가 없으면 완료되자마자) · 이슈 워크트리 정리(미커밋 · push 안 된 커밋이 있으면 남긴다). 팩 레포에 로컬 커밋(push 안 함 · `scripts/board/archive.mjs`). 화면(pane 목록)을 못 읽으면 보관하지 않는다(2026-10-26 결정 D4) |
| **[아카이브]** 탭 | 보관한 일을 월별로 — 제목·요약·레포·커밋 검색, 이슈/계획서·레포 필터. 한 건을 누르면 이슈·요청·진행·결과·검증·커밋이 한 화면에 (`#history` 로 바로 열림) |
| **[삭제]** (열린 이슈) | 휴지통 `.board-trash/<날짜>/` 로 옮긴다(gitignore). 이슈면 연결 경량 계획서·워크트리도. 되살릴 수 있게 지우지 않는다. 떠 있는 에이전트 pane 은 닫지 않는다 |
| **[작업 시작]** (열린 이슈) — 기본이 **아테나**(처리)이고, 팝업에서 **담당 에이전트로 바로(조사만 · 코드 수정 없음)** 로 바꿀 수 있다 | 새 아테나 pane(또는 담당 에이전트 pane)에 지시문을 입력한다(`scripts/screen pane send-text` + Enter). **보내기 전에 창에서 보여주고 고칠 수 있다** |

- 목록은 원본 파일을 따라 바뀐다. 이슈 `status` 를 고치면(아테나) 같이 바뀐다
- 보안: 서버를 띄울 때마다 만드는 토큰과 Origin(`localhost:<포트>`)이 맞는 요청만 쓰기를 받는다. 지시는 아테나·위임 에이전트 pane 에만 보낼 수 있다
- 아테나가 작업 중일 때 보낸 지시는 지금 일이 끝난 뒤 이어서 처리된다
- **결정 콘솔** — 일감 주소로 열린 콘솔(`/plans/….html`)에서 고르고 **[이대로 진행]** 을 누르면 결정이 그 계획서를 만든 아테나 pane(`PLAN.leadPane`)에 입력된다. 아테나는 `scripts/board.sh open <md>` 로 같은 주소를 연다

## 완료 가능 배지
진행 중 이슈 줄은 `docs/issues.md` "완료 기준" 의 신호(확인 결과 · 후속 정리 · fix 커밋 · 계획 done+PR MERGED · reason)를 기계적으로 확인해 전부 채워지면 `완료 가능` 이 붙는다.
- **완료로 옮기는 건 아테나다**(이슈 `status: done`) — 화면에서 끌어 옮기지 않는다. 완료되면 위 자동 보관이 이어 받는다
