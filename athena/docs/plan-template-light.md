# 경량 계획서 템플릿

**모든 작업은 계획서 하나에 묶인다.** 작업의 무게에 따라 둘 중 하나를 쓴다.

| 종류 | 언제 | 파일 | 승인 |
|---|---|---|---|
| 정식 | 사용자가 정할 것이 있거나 여러 레포·담당을 맞춰야 할 때(새 기능·API·구조 변경은 대개 여기) | `plans/{feature,bugfix,refactor}/…` `.md` + `.html`(결정 콘솔) — `docs/plan-template.md` | 결정 콘솔에서 골라 [이대로 진행] |
| **경량** | 그 밖의 모든 작업 — 문구·스타일 수정 · 버그 하나 · 확인·조사 · 직접 부른 에이전트 작업 · 긴급 수정 | `plans/task/YYYYMMDD-<에이전트>-<요약>.md` 하나 — **이 템플릿** | **사용자의 지시가 곧 승인** |

- 손으로 쓰지 않는다. `node scripts/new-plan.mjs --agent <에이전트> --summary "<요약>"` 이 만든다. `scripts/delegate.sh --plan new "<요약>"` 과 현황판 [작업 시작] 은 이걸 부른다
- 작업이 커지면(여러 레포·API 변경·결정이 필요) 정식 계획서로 옮기고 경량판에는 그 경로를 적는다
- 담당 에이전트는 끝날 때 Checkpoint 의 Progress·결과를 채운다(Validation 은 검증 스크립트 · 커밋 뒤 Status 는 `commit.sh` 가 적는다). Studio [작업] 팝업 · pane [상세] 가 이 Status 를 따라 바뀐다
- 버그 수정이면 `AGENTS.md` 5절의 버그 수정 규칙(재현 먼저 · 수정 전·후 비교)을 따른다
- 경량판은 처음에 html 결정 콘솔이 없다 — 리뷰에서 "결정 필요"가 나오면 그때 같은 계획서에 콘솔이 생긴다(`plan-html.mjs --add`)

## 지시 칸 — 짧고 정해진 칸으로

아테나가 넘기는 지시문(`--prompt-file` → `## 지시` 의 인용)은 아래 칸으로 쓴다. 정식 계획서의 `## 지시` 도 같다. `scripts/delegate.sh` 가 띄우기 전에 `scripts/plan-check.mjs` 로 검사해 **경고만** 보여 준다(띄우기는 막지 않는다 · 새 칸이 하나도 없는 옛 계획서는 건너뛴다 · 경고 수는 현황판 [지표] 탭).

```
요청(YYYY-MM-DD): 한두 줄 요약 (←1)
- 할 것: (버그면 재현 · 기대)
- 보존: 바꾸면 안 되는 것
- 조건: 지킬 것 · 확인 방법
- 안 할 것: 하지 말 것
- handoff 전 · 후:
  - 멈춤: 없음
  - 받은 뒤: commit.sh → 레포 설정대로 ship.sh
- 버림:
  - N — 이유
```
- **멈춤 기본값은 `멈춤: 없음`.** 정말 기다려야 하면 무엇을 기다리는지와 근거를 쓴다 — `- 멈춤: <기다릴 것> — 근거: 요청 N줄 | D# | 설정 direct | 규칙 화면` 중 하나(요청 N줄 = 지시 칸 N번째 줄에 기다림 말 · D# = 지시 칸에 그 결정과 기다림 말 · 설정 direct = main 직접 레포 · 규칙 화면 = 화면이 바뀌는 작업). 근거 없는 멈춤 · `멈춤: 없음` 인데 다른 줄의 "확인받고" 같은 기다림 말은 경고다
- 에이전트가 `멈춤:` 에서 실제로 멈추면 마지막 보고 첫 줄을 `⏸ 멈춤: <기다리는 것>` 으로 쓴다 — 끝 알림 훅이 아테나 pane 에 "끝" 대신 멈춤으로 알린다
- 넘기기 말(커밋 · 넘기기 · 머지 · ship.sh)은 handoff 칸에만. 받은 뒤 ship.sh 옵션은 레포 설정(`autoPr` · `actionsHandoff`)과 맞아야 한다 — 모르면 "레포 설정대로"(디스패치 결과의 "올리는 방식" 줄)
- 지시 칸에 진행 상태(받음 · 남은 일 · 끝남)를 쓰지 않는다 — Checkpoint 에 쓴다
- 원본(사용자 글 · 이슈)을 줄였으면 줄 끝에 원본 줄 번호 `(←N,M)`, 뺀 줄은 `- 버림:` 아래 `- N — 이유`. 원본 대조는 원본 파일을 줄 때만 한다(`node scripts/plan-check.mjs --plan <계획서> --orig <원본>`)
- 적힌 경로(`` `a/b.ext` ``)는 본체 · 팩 · 레포에 있어야 한다(새로 만들 파일은 그 줄에 "새로" · "만든다")
- 줄 번호는 `## 지시` 다음 줄이 1
